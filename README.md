# The Crown of Chaos

A Fabric mod for Minecraft 26.2 by Warfist.

## Items

- **Under Crown**: a helmet with diamond-helmet stats. While worn it grants Haste II,
  Night Vision, Hero of the Village and Fortune III on block drops.

## Development

Requires Java 25.

- `./gradlew runClient` starts Minecraft with the mod loaded.
- `./gradlew build` builds the mod jar into `build/libs/`.
- `./gradlew vscode` generates VS Code launch configurations.
