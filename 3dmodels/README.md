# 3D Models

Blockbench exports for the crowns' custom 3D models go here.

For each crown, export from a **Modded Entity** project with **Mojang mappings**:

- `CrownName.java`: the Java entity model export
- `CrownName.png`: the texture the model was painted with

Optionally, also add a **Java Item** model (`.json`) if the crown should look 3D in the hand
and inventory.
